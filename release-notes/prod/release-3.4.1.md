# 🚀 Survey-Service Release 3.4.1 [![Latest](https://img.shields.io/badge/Latest-ffffff00?style=flat\&labelColor=ffffff00\&color=green)](#)

## ✨ Features & Improvements

* **[1765] Internal Caching and Optimization of Program Listing API – Survey Service**
  Added internal caching and performance optimizations to improve the efficiency and response time of the program listing APIs.

* **[1763] Internal Caching and Optimization of Survey & Observation Listing APIs**
  Enhanced survey and observation listing APIs with internal caching and optimizations for improved performance and reduced latency.

* **[1741] Enable Tenant Admin to Create Resources in Survey Service**
  Added support for tenant administrators to create and manage resources within the Survey Service.

---

## 🐞 Bug Fixes

* **[4589] Deeplink Creation Issue with Org Admin Token**
  Fixed an issue where deeplink creation was not working as expected when using Org Admin tokens through Postman/API calls.

* **[4841] Stale Survey and Observation Solutions Visible After Program Cleanup**
  Fixed an issue where survey and observation solutions remained visible after program data cleanup, even though they were no longer consumable.

No additional migration steps are required for this release.
